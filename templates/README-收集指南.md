# 企业材料收集指南（README）

本指南面向**负责收集、填写企业材料的工作人员**。你只需要：① 填一张 Excel 表；② 按文件夹整理证明材料；③ 打包上传。系统会自动把数据归入知识库。

---

## 一、你要准备什么

| 材料 | 说明 |
|---|---|
| `企业材料收集表.xlsx` | 下载模板后填写（9 个 sheet） |
| `证明材料/` 文件夹 | 按 sheet 分文件夹放 PDF/图片 |

最终打包成 **一个 ZIP**（Excel + 证明材料文件夹）上传。

---

## 二、Excel 怎么填（9 个 sheet）

打开模板，按顺序填：

| Sheet | 填什么 | 一行 = ? | 需要证明材料？ |
|---|---|---|---|
| 填写说明 | 不用填，先看一遍 | — | — |
| 企业基本信息 | 公司的基本情况 + 能力范围 | 只填 1 家公司 | 营业执照 |
| 资质认证 | 资质证书、许可证、体系认证 | 一条资质 | ✅ |
| 类似业绩 | 历史项目案例 | 一个项目 | ✅ |
| 项目人员 | 可投入项目的人员 | 一个人 | ✅ |
| 财务证明 | 审计报告、银行资信、社保等 | 一份证明 | ✅ |
| 技术产品 | 产品、系统、服务 | 一个产品 | 可选 |
| 技术参数 | 产品的关键指标 | 一条参数 | ✅ |
| 证照凭证 | 产品认证、专利、软著、商标 | 一张证/一个知产 | ✅ |

### 填写规则

- **带 ▼ 的列**：必须从下拉菜单选，别手输。
- **日期**：统一 `YYYY-MM-DD`，如 `2024-03-01`。
- **金额单位**：合同金额 = 元；营业收入/资产总额 = 万元。
- **多值字段**（能力清单、服务范围等）：用顿号「、」分隔，如「数字孪生、智慧城市、AI 智能体」。
- **黄色示例行**：是参考样例，填写时覆盖成真实数据即可。
- 没把握的字段**宁可留空**，也不要乱填。

## 三、证明材料怎么放（按文件夹分组）

```
证明材料/
├── 资质认证/          ← 文件夹名 = sheet 名
│   └── 3/             ← 序号 = 该行「序号」（3、4、5…）
│       ├── 1.png      ← 这条资质的第 1 页
│       ├── 2.png      ← 第 2 页
│       └── 3.pdf      ← 也可以是 PDF 等格式
├── 类似业绩/
│   └── 5/
│       └── 1.png
├── 项目人员/
├── 财务证明/
├── 技术产品/
├── 技术参数/
└── 证照凭证/
```

### 命名规则（重要）

| 规则 | 示例 |
|---|---|
| 文件夹名 = sheet 名 | `资质认证`、`类似业绩`… |
| 一个 sheet 行 = 一个文件夹，文件夹名 = 该行「序号」 | 序号 3 → `资质认证/3/` |
| 文件夹内文件按 1、2、3… 命名，不用补零 | `1.png`、`2.png`、`3.pdf` |
| 顺序由系统按数字排 | 100 张、1000 张都不会乱 |
| 支持格式 | PDF、PNG、JPG 等都可以，也能混放 |

> 例：`资质认证` sheet 里序号=3 那行是「ISO9001 证书」，那它的扫描件就放进 `资质认证/3/` 文件夹，页面依次命名为 `1.png`、`2.png`…

## 四、怎么提交

1. 确认 Excel 填完、证明材料按文件夹放好。
2. 把 Excel 和 `证明材料/` 文件夹一起**压缩成一个 ZIP**。
3. 打开系统「材料上传」页面 → 拖入 ZIP → 上传。
4. 系统会自动**校验**：缺证明、格式错、日期错都会逐行提示。
5. 按提示改完重新上传，直到「导入成功」。

---

## 五、常见问题

**Q：一个证书有多页/多张图怎么办？**
A：把该证书的所有页面放进它对应的序号文件夹，按 1、2、3… 命名：`资质认证/3/1.png`、`资质认证/3/2.png`、`资质认证/3/3.png`。100 张、1000 张都没问题，顺序由系统按数字排。

**Q：某条记录没有证明材料怎么办？**
A：技术产品、企业基本信息可以没有；其余类尽量都附证明。没有证明的那条会在校验时提示，你可选择「仍导入」或「补齐后导入」。

**Q：下拉菜单没有我要的选项？**
A：先选最接近的「其他」，并在「备注」里写明，或联系系统管理员加词表。
