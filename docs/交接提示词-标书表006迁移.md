## 五、设计原则（沿用 004 的既定方针，别推翻）

1. **只有需要"按字段查询/治理"的才建标量列**；复杂派生结构**原样落 jsonb**（前端读出来即用、无损回放）。
2. **不拆新表以免过度建模**：能用 jsonb 表达的嵌套结构（如 `matchedParameters` 三层嵌套 units→details）就整列透出，**不要拆成标量列**（会丢层级）。
3. **可重建的派生字段不落列**，由读取层从既有表拼回（`matchedObjectIds`→`match_item_fact`；`evidenceItems`→`match_item_evidence`；`matchedMaterialIds`→`fact_snapshot.materialIds`；`evidenceIds`→`match_item_evidence(source_type='evidence')`）。
4. **本批只加 schema，不改应用代码**：`store.py` / `bid_writing/*` 一行不动（切读是后续阶段的事）。
