## 5. PDF 附件自动逐页转图插入 Word 标书（待做）

**目标**：标书/响应文件 docx 生成时，遇到 PDF 附件自动逐页渲染成图片、按页序插入 Word；用户上传时直接丢 PDF，无需人工先转图。

**背景**：
- 现状 `store.py::generate_response` 的 docx 输出只写文字（标题/列表/引用/段落），**不插入任何图片**。
- PDF 处理目前只做文字抽取（`pypdf`/`pdfplumber`），无「页 → 图片」渲染能力。
- 证明材料导入已支持「一个序号 = 一个文件夹 = N 个文件」（importer 已改），PDF 可作为其中一种文件。

**方案**：
- 依赖选 `pypdfium2`（Apache-2.0 / BSD-3-Clause，宽松、可商用闭源，底层 PDFium）。**不用 PyMuPDF**（AGPL-3.0，企业闭源项目有传染性 copyleft 风险）。
- 实现：`generate_response` 组装 docx 时，对从 `evidencePath`（证据文件夹）枚举出的 PDF 附件，用 `pypdfium2` 逐页渲染 PNG（150~200 DPI），再 `python-docx` 的 `add_picture()` 按页序插入。
- 页序：按 `证明材料/{sheet}/{序号}/{1..N}` 的数字序。

**待办**：
- [ ] `requirements.txt` 加 `pypdfium2`
- [ ] 实现 PDF → PNG 逐页渲染工具函数
- [ ] `generate_response` 的 docx 分支接入「附件 → 图片按序插入」
- [ ] 前端标书生成页暴露「PDF 附件转图插入」开关（默认开）
