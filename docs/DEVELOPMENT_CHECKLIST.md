# 招投标智能体单公司版开发清单

## 1. 项目范围

当前阶段只支持一个投标主体：

> 北京优锘科技股份有限公司

暂不实现：

- 多公司、多租户
- 用户登录和权限隔离
- 自动报名
- 自动报价
- 自动提交正式投标文件
- 需要登录、验证码或付费权限的网站抓取
- 多智能体协同

系统定位：

```text
自动搜标
  -> 项目相关性筛选
  -> 公告资格粗匹配
  -> 招标文件条款细匹配
  -> 资格匹配分
  -> 投标应答预审分
  -> 风险和补证清单
  -> 响应文件底稿
```

## 2. 工作规则

- [x] 每次只完成一个明确的开发任务
- [x] 每完成一项，更新本文件的复选框
- [x] 每个结论必须尽量关联企业材料或招标文件证据
- [x] 资料不足时输出“待核验”或“待补材料”
- [x] 历史投标文件不能直接等同于当前有效证明
- [x] 否决性条款优先于综合评分
- [x] 大模型负责理解和抽取，规则引擎负责最终评分和裁决
- [ ] 每次 AI 或规则运行都记录输入、版本、输出和异常
