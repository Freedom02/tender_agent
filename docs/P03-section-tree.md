# P03 章节树与大章节切分

> 状态：已完成，待阶段验收
> 日期：2026-09-19

## 本阶段结论

章节边界先由解析结构和编号规则确定，章节分类不参与边界判断。LLM 暂不参与 P03：当前发现的主要错误是字符归一化、编号层级和明显数字行误识别，均可以用确定性规则稳定修复。

## 已完成

- [x] 统一支持 DOCX/DOC/PDF 文本块输入。
- [x] 标题判断继续优先使用样式、outline level、章节编号和标题关键词。
- [x] 对 PDF 字体提取出的兼容汉字做 NFKC 归一化，例如 `第⼀章` 统一为 `第一章`。
- [x] 修正阿拉伯数字编号层级：`1.1` 作为二级标题，`1.1.1` 作为三级标题。
- [x] 过滤明显的金额/数量行，例如 `1.00 900,000.00 批`。
- [x] 过滤带有明显条款动作词的长句，避免把正文规则误认成标题。
- [x] 保留父子关系、section path、起止 segment、起止 locator 和 `isMajor` 标记。
- [x] 一级章节或 `level <= 1` 的节点标记为大章节，前置内容也作为显式隐式节点保留。
- [x] 章节分类仍是附加诊断信息，不改变章节边界。

## 当前章节流程

```text
DocumentIR.segments
  -> 标题候选识别
  -> 目录/页码/明显正文过滤
  -> 标题层级判断
  -> 父子关系构建
  -> 按下一个同级或上级标题确定结束位置
  -> 生成 sectionPath、segmentIds、locator
  -> 标记 isMajor
  -> 另行记录 sectionType，不参与边界
```
